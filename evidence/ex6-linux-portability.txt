## 2. Thay the AIRFLOW_UID (cach Linux dung .env)
$ AIRFLOW_UID=1000 docker compose config | grep user:
    user: '1000:0'
$ docker compose config | grep user:      # mac dinh, khong co .env
    user: '50000:0'
